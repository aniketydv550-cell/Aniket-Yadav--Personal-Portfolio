# Personal Portfolio Website

A simple and responsive personal portfolio website created to showcase my profile, technical skills, projects, and contact information.

## 📌 Project Overview

This portfolio website provides an introduction to **Aniket Yadav** as a web developer. It contains dedicated sections for personal information, technical skills, projects, and a contact form.

The website is built using standard **HTML5** and follows a clean, semantic structure.

## ✨ Features

* **About Section**

  * Personal introduction
  * Professional profile image
  * Short description of development experience

* **Technical Skills**

  * Frontend development
  * Backend architecture
  * Database management
  * DevOps and development tools

* **Projects**

  * E-Commerce Platform Engine
  * Real-Time Weather Analytics Dashboard

* **Contact Section**

  * Name input
  * Email input
  * Message textarea
  * Email-based contact form

* **Navigation**

  * About
  * Skills
  * Projects
  * Contact

## 🛠️ Technologies Used

* HTML5
* Semantic HTML elements
* HTML Forms
* External image assets
* Git/GitHub for project repositories

The skills presented in the portfolio also include JavaScript, TypeScript, React, Next.js, Node.js, Express, Python, PostgreSQL, MySQL, MongoDB, Docker, and CI/CD.

## 🚀 Getting Started

### 1. Clone or Download the Project

Download the project files or clone the repository to your local machine.

### 2. Open the Project

Navigate to the project directory:

```bash
cd portfolio
```

### 3. Run the Website

Since this project is based on HTML, no backend server or package installation is required.

Simply open:

```text
index.html
```

in any modern web browser.

For a better development experience, you can also use an extension such as **Live Server** in Visual Studio Code.
